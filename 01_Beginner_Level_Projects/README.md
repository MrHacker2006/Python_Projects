# 🚀 Beginner-Level Python Projects

Welcome to the **Beginner-Level Projects** repository!  

This is the first phase of my Python learning journey, where I build foundational mini-projects to strengthen core concepts like logic, conditionals, loops, functions, user input, and working with modules.

Each project is designed to be short, focused, and practical — ideal for hands-on learning and rapid skill building.

---

## 📁 Project Structure

Each folder in this repository contains:
- ✅ A standalone Python script
- 📝 A `README.md` file explaining the project
- 📦 A `requirements.txt` file (if external libraries are used)
- 📸 Screenshots (if the project has a GUI or output)
